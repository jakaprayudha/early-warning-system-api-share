DOKUMENTASI
Endpoint menggunakan HTTP tanpa enkripsi. Pengujian langsung dapat mengekspos token di jaringan. Gunakan token khusus pengujian, bukan token produksi. Untuk produksi, gunakan layanan API HTTPS.
